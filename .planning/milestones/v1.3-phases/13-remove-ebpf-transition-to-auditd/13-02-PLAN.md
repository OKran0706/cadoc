# Phase 13 Plan - Wave 2: Core Auditd Infrastructure (13-02)

## Goal
Implement the core Auditd management and IPC synchronization.

<task id="13.2.1" wave="2" autonomous="true" requirements="REQ-FIM-02">
    <read_first>
        - src/sentinel/internal/auditmon/
    </read_first>
    <action>
        Implement `AuditctlManager` in the Sentinel daemon.
        1. Create a wrapper around the `auditctl` CLI.
        2. Implement `AddWatch(path, key)` and `RemoveWatch(path, key)` using `auditctl -w` and `auditctl -W`.
        3. Ensure rules are injected with `-p wa` (write/attribute) permissions.
    </action>
    <acceptance_criteria>
        - Sentinel daemon can successfully execute `auditctl` commands.
        - `auditctl -l` reflects rules injected by the daemon.
    </acceptance_criteria>
</task>

<task id="13.2.2" wave="2" autonomous="true" requirements="REQ-IPC-01">
    <read_first>
        - src/sentinel/cmd/sentinel-a/audit_consume.go
        - src/sentinel/cmd/sentinel-a/main.go
    </read_first>
    <action>
        Enhance the IPC bridge for Stealth Registry (Canary Map) synchronization.
        1. Define a `SET_MAP` control message in the IPC protocol.
        2. Implement the "push" logic in the main daemon to broadcast map updates to the worker.
        3. Update the worker to receive and cache the map in an in-memory registry.
    </action>
    <acceptance_criteria>
        - Worker logs show "Map received from daemon" upon synchronization.
        - Registry is stored in-memory only (Zero-Disk).
    </acceptance_criteria>
</task>

<task id="13.2.3" wave="2" autonomous="true" requirements="REQ-FIM-03">
    <read_first>
        - src/sentinel/internal/auditmon/aggregator.go
    </read_first>
    <action>
        Implement "Bare Essentials" filtering in the `audit-consume` worker.
        1. Update the aggregator to check every incoming audit event against the synced Canary Map.
        2. Drop events that do not match a canary path.
        3. Strip event metadata to: `timestamp`, `path`, `pid`, `uid`, `action`.
    </action>
    <acceptance_criteria>
        - IPC traffic only contains events for registered canary paths.
        - Payload fields are limited to the "Bare Essentials" set.
    </acceptance_criteria>
</task>
