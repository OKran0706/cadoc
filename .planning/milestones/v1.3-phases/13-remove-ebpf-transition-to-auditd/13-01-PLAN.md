# Phase 13 Plan - Wave 1: eBPF & Tetragon Removal (13-01)

## Goal
Remove all eBPF/Tetragon code and dependencies.

<task id="13.1.1" wave="1" autonomous="true" requirements="REQ-FIM-01">
    <read_first>
        - src/sentinel/cmd/sentinel-a/main.go
        - src/sentinel/internal/engine/engine.go
    </read_first>
    <action>
        Remove all Tetragon/eBPF code from the codebase.
        1. Delete the directory `src/sentinel/internal/ebpf/` if it exists.
        2. Remove Tetragon gRPC client initialization from `main.go`.
        3. Remove eBPF telemetry hooks from the main event engine.
    </action>
    <acceptance_criteria>
        - `grep -r "tetragon" src/` returns zero results.
        - `grep -r "cilium/ebpf" src/` returns zero results.
    </acceptance_criteria>
</task>

<task id="13.1.2" wave="1" autonomous="true" requirements="REQ-SEC-01">
    <read_first>
        - deploy/sentinel.service
    </read_first>
    <action>
        Update the systemd unit file to remove eBPF-related capabilities.
        1. Remove `CAP_BPF` and `CAP_PERFMON` from `CapabilityBoundingSet` and `AmbientCapabilities`.
        2. Keep `CAP_NET_ADMIN` and `CAP_SYS_RESOURCE` if required for other operations.
    </action>
    <acceptance_criteria>
        - `deploy/sentinel.service` does not contain `CAP_BPF` or `CAP_PERFMON`.
    </acceptance_criteria>
</task>

<task id="13.1.3" wave="1" autonomous="true" requirements="REQ-DEP-01">
    <read_first>
        - go.mod
    </read_first>
    <action>
        Clean up Go dependencies.
        1. Remove `github.com/cilium/tetragon` and `github.com/cilium/ebpf` from `go.mod`.
        2. Run `go mod tidy` to prune `go.sum`.
    </action>
    <acceptance_criteria>
        - `go.mod` does not contain Tetragon or ebpf dependencies.
    </acceptance_criteria>
</task>
