# 06-01: Resilient Vault Polling

## Objective
Implement exponential backoff logic for Vault re-authentication. When Sentinel restarts without a join-token, it should attempt to re-authenticate using its persisted mTLS cert. If blocked (403), it must enter a non-crashing polling loop with exponential backoff.
