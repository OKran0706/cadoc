<objective>
Fix interactions with the host OS auditd subsystem and internal Unix sockets:
- WR-003: `auditctl -D` flushes ALL rules on the system instead of just canary rules. Fix to target only our keys.
- WR-004: `server.go` socket scanner lacks a read deadline, allowing crashed plugins to hold connections indefinitely.
</objective>

<tasks>

## Task 1 — Fix WR-003: Targeted rule deletion

**File:** `src/sentinel/internal/auditmon/auditctl.go`

In `ClearAll`, replace:
```go
cmd := exec.Command("auditctl", "-k", m.key, "-D")
```
with:
```go
// auditctl -D flushes ALL rules on the system. To delete only our rules safely,
// we list them and delete each one by exact string match.
script := fmt.Sprintf("auditctl -l | grep ' -k %s' | while read -r rule; do auditctl -d $rule; done", m.key)
cmd := exec.Command("sh", "-c", script)
```

## Task 2 — Fix WR-004: Set read deadline on Unix socket

**File:** `src/sentinel/internal/auditmon/server.go`

In `handleConnection` (around line 96):
```go
func handleConnection(conn net.Conn) {
    // ...
    scanner := bufio.NewScanner(conn)
    for {
        conn.SetReadDeadline(time.Now().Add(30 * time.Second))
        if !scanner.Scan() {
            break
        }
        line := scanner.Text()
        // ...
    }
}
```
