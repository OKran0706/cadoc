<objective>
Fix logical edge cases in the canary deployer:
- WR-005: `deployer_daemon` removes active canaries before calling `Deploy`. If `Deploy` fails, the system is left with 0 canaries.
- WR-007: `deployer.go` timestamp blending ignores empty directories, resulting in empty strings for `blended_mtime`.
</objective>

<tasks>

## Task 1 — Fix WR-005: Safe canary rotation order

**File:** `src/sentinel/internal/deployer_daemon/daemon.go`

In the deployment loop (around line 43):
Replace:
```go
for _, c := range activeCanaries {
    _ = os.Remove(c.Path)
}
newCanaries, err := deployer.Deploy(profile, templateDir, false)
if err != nil {
    // ...
```
With:
```go
newCanaries, err := deployer.Deploy(profile, templateDir, false)
if err != nil {
    log.Printf("Deployer Daemon: error during deployment: %v — keeping existing canaries", err)
} else {
    // Only remove old canaries after successful new deployment
    for _, c := range activeCanaries {
        _ = os.Remove(c.Path)
    }
    activeCanaries = newCanaries
    
    // ... Broadcast the new paths to the consumer
```

## Task 2 — Fix WR-007: Handle empty directory in blending

**File:** `src/sentinel/internal/deployer/deployer.go`

In `blendTimestamp` and `getBlendedMtime`:
If the directory has no other files, we should probably fall back to the directory's own mtime or `time.Now()`.

```go
func getBlendedMtime(dirPath string, excludePrefix string) string {
    // ...
    // If we get here, no suitable file was found. Fallback to directory mtime or current time.
    dirInfo, err := os.Stat(dirPath)
    if err == nil {
        return dirInfo.ModTime().UTC().Format(time.RFC3339Nano)
    }
    return time.Now().UTC().Format(time.RFC3339Nano)
}
```

```go
func blendTimestamp(dirPath string, targetPath string, excludePrefix string) {
    // ...
    // If no suitable file found, do not change mtime (or change to dir mtime).
    // The current behaviour is to return silently, which might be okay if we just fallback in getBlendedMtime.
    // Let's add the fallback to both.
}
```
