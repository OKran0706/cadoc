<objective>
Fix state management and error parsing fragility:
- WR-006: `auditmon.StartServer` uses package-level globals (`workers`, `workersMu`, `currentMapMsg`). Move these into a `Server` struct.
- WR-009: `vault.client.go` detects 403s using `strings.Contains(err.Error(), "403")`, which is fragile. Replace with `errors.As(err, &api.ResponseError)`.

## Task 1 — Fix WR-009: Structured Vault errors

**File:** `src/sentinel/internal/vault/client.go`

In `FetchKey` and `VerifyTicket` (or any method using `errStr` matching):
Instead of:
```go
errStr := err.Error()
switch {
case strings.Contains(errStr, "403"):
    return nil, fmt.Errorf("read secret %s: %w", path, ErrForbidden)
case strings.Contains(errStr, "404"):
    return nil, fmt.Errorf("read secret %s: %w", path, ErrNotFound)
}
```
Use:
```go
var respErr *api.ResponseError
if errors.As(err, &respErr) {
    switch respErr.StatusCode {
    case http.StatusForbidden:
        return nil, fmt.Errorf("read secret %s: %w", path, ErrForbidden)
    case http.StatusNotFound:
        return nil, fmt.Errorf("read secret %s: %w", path, ErrNotFound)
    }
}
```

## Task 2 — Fix WR-006: Server struct refactor

**File:** `src/sentinel/internal/auditmon/server.go`

Convert package-level variables:
```go
var (
    workers       = make(map[net.Conn]struct{})
    workersMu     sync.Mutex
    currentMapMsg string
)
```
into a `Server` struct:
```go
type Server struct {
    workers       map[net.Conn]struct{}
    workersMu     sync.Mutex
    currentMapMsg string
}

func StartServer(ctx context.Context, socketPath string, handler func(*AuditEvent)) *Server {
    s := &Server{
        workers: make(map[net.Conn]struct{}),
    }
    // ... move listen logic into go func
    return s
}

func (s *Server) BroadcastControlMessage(msg string) { ... }
```
