# Plan 14-01: Subcommand Parsing Fix & PID Hardening

## Goal
Move the `audit-consume` subcommand check to before `flag.Parse()` so it is invoked cleanly by audispd without flag conflicts. Harden the PID file write by ensuring the directory exists with correct permissions before writing.

## Tasks

### Task 1: Move Subcommand Check Before flag.Parse()

<read_first>
- src/sentinel/cmd/sentinel-a/main.go (full file — understand current flag and subcommand order)
- src/sentinel/cmd/sentinel-a/audit_consume.go (to confirm runAuditConsumer signature and deps)
</read_first>

<action>
In `src/sentinel/cmd/sentinel-a/main.go`, restructure `main()` so the subcommand check occurs immediately after the function opens, before any flag definitions or `flag.Parse()`.

Current order (lines 36-53):
```go
func main() {
    devMode := flag.Bool(...)
    configPath := flag.String(...)
    // ... more flags ...
    flag.Parse()

    // 0. Subcommand Check (audispd plugin mode)
    if len(os.Args) >= 2 && os.Args[1] == "audit-consume" {
        runAuditConsumer()
        return
    }
```

Target order:
```go
func main() {
    // 0. Subcommand routing — must come BEFORE flag.Parse()
    // audispd invokes this binary with "audit-consume" as argv[1].
    // Flags are not parsed in this path.
    if len(os.Args) >= 2 && os.Args[1] == "audit-consume" {
        runAuditConsumer()
        return
    }

    devMode := flag.Bool("dev", false, "Run in development mode (skips auth/ingestion bootstrap)")
    configPath := flag.String("config", "/opt/sentinel/config/sentinel.yaml", "Path to sentinel config")
    joinToken := flag.String("join-token", "", "Initial vault bootstrap token")
    testSign := flag.Bool("test-sign", false, "Sign a test event and exit")
    deployerProfile := flag.String("deployer-profile", "", "Canary profile (app-server, db-server, etc.)")
    deployerConfigDir := flag.String("deployer-config", "/opt/canary/config", "Path to canary profile configs")
    deployerTemplateDir := flag.String("deployer-templates", "/opt/sentinel/templates", "Path to canary templates")
    deployerInterval := flag.Int("deployer-interval", 3600, "Base canary rotation interval (seconds)")
    deployerMaxJitter := flag.Int("deployer-max-jitter", 1800, "Max random jitter for rotation (seconds)")
    flag.Parse()

    log.Println("=== SENTINEL-A DAEMON BOOTING ===")
    // ... rest of main ...
```
</action>

### Task 2: Harden PID File Writing

<read_first>
- src/sentinel/cmd/sentinel-a/main.go (lines around the PID write block, currently ~L211)
</read_first>

<action>
Replace the current PID write block:
```go
if err := os.WriteFile("/run/canary/sentinel-a.pid", []byte(fmt.Sprintf("%d", os.Getpid())), 0644); err != nil {
    log.Printf("Warning: could not write PID file: %v", err)
}
```

With the hardened version:
```go
const pidDir = "/run/canary"
const pidFile = pidDir + "/sentinel-a.pid"

if err := os.MkdirAll(pidDir, 0700); err != nil {
    log.Printf("Warning: could not create PID directory %s: %v", pidDir, err)
} else if err := os.WriteFile(pidFile, []byte(fmt.Sprintf("%d\n", os.Getpid())), 0644); err != nil {
    log.Printf("Warning: could not write PID file %s: %v", pidFile, err)
} else {
    log.Printf("PID file written: %s (pid=%d)", pidFile, os.Getpid())
}
```

Note: systemd's `ExecStartPre=/usr/bin/mkdir -p /run/canary` already handles directory creation in the service unit, but this ensures the binary is safe when run outside systemd (e.g., manual invocation, testing).
</action>

<acceptance_criteria>

- `grep "0700" src/sentinel/cmd/sentinel-a/main.go` returns a match.
- File compiles: `go build ./cmd/sentinel-a/` exits 0.
</acceptance_criteria>
