## 2. Integration Check (Post-Hoc Fixes)

The audit initially flagged several integration gaps which were resolved during the final stabilization phase:

- **Vault Policy Alignment**: Expanded `sentinel-a` policy to include access to `signer` and `control` paths.
- **mTLS Trust Chain**: Updated `cert-generator` to include SANs and fixed `verifyIngestion` to use the mTLS client.
- **Crypto Synchronization**: Re-aligned the Ed25519 seed in Vault with the `ORG_PUBLIC_KEY` in the Ingestion Service.
- **Build Integrity**: Resolved stale binary issues with fresh Docker layers and fixed missing imports.

## 3. End-to-End Flow Validation

The full pipeline has been verified end-to-end:
1. **Bootstrap**: Sentinel-A unwraps Vault token → fetches TLS certs → fetches Signer seed.
2. **Liveness**: Sentinel-A posts mTLS heartbeat → Ingestion Service verifies signature → Updates Redis.
3. **Telemetry**: Sentinel-A posts event → Ingestion Service verifies signature → Routes to Kafka (`canary-events`).
