## Task 3 — Fix IN-005: Config validation

**File:** `src/sentinel/internal/config/config.go`

Add `Validate()` method to `Config` struct:
```go
func (c *Config) Validate() error {
    if c.Watchdog.IngestionURL == "" {
        return fmt.Errorf("ingestion_url is required")
    }
    if c.Watchdog.KeySource == "" {
        return fmt.Errorf("key_source is required")
    }
    return nil
}
```
And call it in `Load`:
```go
    // ...
    if err := json.Unmarshal(body, cfg); err != nil {
        return nil, err
    }
    if err := cfg.Validate(); err != nil {
        return nil, fmt.Errorf("invalid configuration: %w", err)
    }
    return cfg, nil
```
