## Task 1 — Fix IN-001: Unique fallback IDs

**File:** `src/sentinel/internal/auditmon/aggregator.go`

In `extractAuditID`, instead of returning `"unknown"`, return a uniquely generated ID so unparseable events do not collide. Or better, just drop it. Returning a unique ID per line (like `fmt.Sprintf("unknown-%d", time.Now().UnixNano())`) ensures they won't group together improperly.

```go
func extractAuditID(raw string) string {
    // msg=audit(17137123.123:456)
    start := strings.Index(raw, "audit(")
    if start == -1 {
        return fmt.Sprintf("unknown-%d", time.Now().UnixNano())
    }
    end := strings.Index(raw[start:], ")")
    if end == -1 {
        return fmt.Sprintf("unknown-%d", time.Now().UnixNano())
    }
    return raw[start+6 : start+end]
}
```
