<objective>
Fix two silently ignored errors in main.go that have security-sensitive consequences:
- CR-003: `_ = sysutil.PersistPublicCerts(...)` — if cert persistence fails, the daemon will be permanently locked out after any restart.
- CR-004: `_ = vaultClient.SetTLSConfig(...)` — if TLS config fails to apply, all Vault calls use stale/nil TLS, silently degrading to insecure connections.
</objective>

<tasks>

## Task 1 — Fix CR-003: Handle `PersistPublicCerts` error

**File:** `src/sentinel/cmd/sentinel-a/main.go`, line 135

Current code:
```go
// 1d. Persist State (Public Only)
if *joinToken != "" {
    _ = sysutil.PersistPublicCerts(stateDir, certCA, certClient)
}
```

**Problem:** If `PersistPublicCerts` fails (disk full, wrong permissions on `stateDir`), the daemon continues running. On the next restart — after a kill switch, crash, or upgrade — the recovery path calls `LoadPersistedCerts` and fails, causing a permanent lockout.

**Fix:** Treat cert persistence failure as fatal:
```go
// 1d. Persist State (Public Only)
if *joinToken != "" {
    if err := sysutil.PersistPublicCerts(stateDir, certCA, certClient); err != nil {
        log.Fatalf("Failed to persist certificates to %s: %v — restart recovery will be impossible", stateDir, err)
    }
    log.Printf("Certificates persisted to %s", stateDir)
}
```

## Task 2 — Fix CR-004: Handle `vaultClient.SetTLSConfig` error

**File:** `src/sentinel/cmd/sentinel-a/main.go`, line 139

Current code:
```go
// 1e. Finalize Client Initialization
_ = vaultClient.SetTLSConfig(tlsConfig)
s, err = signer.New(cfg.Signing, vaultClient)
```

**Problem:** `SetTLSConfig` internally calls `api.NewClient`, which can fail if the TLS config is malformed. Ignoring this means the Vault client may continue using an old/nil TLS config, making all subsequent Vault operations use incorrect credentials silently.

**Fix:**
```go
// 1e. Finalize Client Initialization
if err := vaultClient.SetTLSConfig(tlsConfig); err != nil {
    log.Fatalf("Failed to apply TLS config to Vault client: %v", err)
}
s, err = signer.New(cfg.Signing, vaultClient)
```
