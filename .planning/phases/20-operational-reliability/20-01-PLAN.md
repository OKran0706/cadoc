<objective>
Fix dropped errors and goroutine exits in the telemetry and heartbeat systems:
- WR-001: Two calls to `ic.Post` in `selfmon.go` silently drop errors. Add explicit logging.
- WR-002: Transient signing errors in the heartbeat goroutine (`main.go`) cause the entire goroutine to `return`, leading to silent telemetry death. Change to `continue`.
</objective>

<tasks>

## Task 1 — Fix WR-001: Log `ic.Post` errors in `selfmon.go`

**File:** `src/sentinel/internal/selfmon/selfmon.go`

In `Init`, replace:
```go
ic.Post(ctx, payload)
```
with:
```go
if err := ic.Post(ctx, payload); err != nil {
    log.Printf("[selfmon] Failed to post mode-selection event: %v", err)
}
```

In `MonitorAuditSubsystem` (or wherever the second `ic.Post` is), replace:
```go
ic.Post(ctx, pay)
```
with:
```go
if err := ic.Post(ctx, pay); err != nil {
    log.Printf("[selfmon] Failed to post audit subsystem event: %v", err)
}
```

## Task 2 — Fix WR-002: Change heartbeat `return` to `continue`

**File:** `src/sentinel/cmd/sentinel-a/main.go`

In the heartbeat goroutine (around line 364), replace:
```go
if err != nil {
    log.Printf("[selfmon] Failed to sign tamper event: %v", err)
    return
}
```
with:
```go
if err != nil {
    log.Printf("[selfmon] Failed to sign heartbeat event: %v", err)
    continue
}
```
