# Plan 15-02: Eliminate _ Ignores in Event Pipeline & exec.Command

## Goal
Fix all ignored errors in `main.go`:
1. Replace `strings.Contains(err.Error(), "403")` with `errors.Is(err, vault.ErrForbidden)` in `pollKillSwitch`.
2. Replace every `envelope, _ := s.SignEvent(...)` and `payload, _ := signer.MarshalEnvelope(...)` with log+skip pattern.
3. Add error logging to `exec.Command("systemctl").Run()`.

## Tasks

### Task 1: Replace Vault String Matching with errors.Is

<read_first>
- src/sentinel/cmd/sentinel-a/main.go (pollKillSwitch function, ~L351-L428)
- src/sentinel/internal/vault/client.go (to confirm ErrForbidden was added in 15-01)
</read_first>

<action>
In `pollKillSwitch`, replace:
```go
if strings.Contains(err.Error(), "403") {
    log.Println("Vault token expired (403). Attempting refresh...")
    if err := refreshVaultAccess(cfg, vc, stateDir); err != nil {
        log.Printf("Vault recovery failed: %v", err)
    }
}
```

With:
```go
if errors.Is(err, vault.ErrForbidden) {
    log.Println("[killswitch] Vault token expired (403) — attempting refresh...")
    if err := refreshVaultAccess(cfg, vc, stateDir); err != nil {
        log.Printf("[killswitch] Vault recovery failed: %v", err)
    }
}
```

Ensure `"errors"` is in the import block (it should already be present from standard library usage; confirm).
</action>
